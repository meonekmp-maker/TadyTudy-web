# TadyTudy web

Samostatný jednostránkový web bez balíčků, sestavování a JavaScriptu.

## Lokální náhled

Otevřete index.html v Chrome nebo Edge. Po změně HTML či CSS soubor uložte a obnovte stránku. Ve VS Code můžete také použít existující rozšíření Live Server.

## GitHub Pages

Do kořene webového repozitáře zkopírujte index.html, style.css a složky images a fonts. Zachovejte již nastavený CNAME a konfiguraci domény. Tato složka je oddělená od Flutter webu ve složce web.

Odkaz Google Play používá ID tadytudy.app z Android konfigurace. Před zveřejněním ověřte dostupnost veřejného záznamu aplikace. Kontaktní e-mail je tadytudy.app@gmail.com.

Grafické podklady a písmo jsou převzaté z aplikace. Licence písma je ve fonts/OFL_NunitoSans.txt.
